# MikroMeet Documentation

**The minimalist documentation site for MikroMeet.**

MikroMeet Documentation is the public docs site for MikroMeet, built with
Astro Starlight and written for people installing, configuring, and deploying
self-hosted video meetings.

## Features

- **Astro Starlight docs** with navigation, search, and responsive layout
- **Getting started pages** for introduction and installation
- **Guides** for meeting features, configuration, and deployment
- **Reference material** for server behavior and API endpoints
- **Custom theme** aligned with the Mikro suite
- **Static output** that can be hosted anywhere

## Read Online

The public documentation is available at [mikrosuite.com/meet/docs](https://mikrosuite.com/meet/docs).

## Install MikroMeet

Download the latest app and API release archives from GitHub Releases or these stable URLs:

- `https://releases.mikrosuite.com/mikromeet_app_latest.zip`
- `https://releases.mikrosuite.com/mikromeet_api_latest.zip`

## Content

The docs cover introduction, installation, meeting features, configuration, deployment, server options, and API endpoints.

## Deployment

The docs site is static and can be hosted anywhere. The app and API release archives are separate from the documentation site.
